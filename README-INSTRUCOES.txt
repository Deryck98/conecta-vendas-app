PACOTE SEO - CONECTA VENDAS

1. Envie todo o conteúdo desta pasta para a raiz do repositório conecta-vendas-app.
2. Substitua o index.html existente pelo novo.
3. Mantenha no repositório todas as imagens já usadas pelo catálogo (Neos.png, Fluo.png, Nmax.png etc.).
4. Confirme que estes endereços abrem:
   https://deryck98.github.io/conecta-vendas-app/sitemap.xml
   https://deryck98.github.io/conecta-vendas-app/robots.txt
5. No Google Search Console, abra Sitemaps e envie: sitemap.xml
6. Solicite a indexação da página inicial e das páginas dos principais modelos.

Observação: o GitHub diferencia letras maiúsculas e minúsculas nos nomes das imagens. Não renomeie as imagens existentes.
